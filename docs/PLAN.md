# План рефактора

Живой документ с планом, треками A/B, точками стыка и дорожной картой:
https://claude.ai/artifact/4HchJRo7EYBaExWxxw2Kn8

Коротко:

- **Фаза 0 — фундамент** (этот коммит): стек, токены, UI-кит, API-клиент + MSW, auth, AppShell, роуты-заглушки, CI.
- Разработка — против локального бэкенда и демо-базы (`../local-proj`). Разделов в базе ~200, но рисуют их
  несколько движков — см. [sections.md](sections.md).
- **Трек A** — журнал, кабинеты, групповые занятия, график работы, движок графиков и дашбордов, уведомления.
- **Трек B** — движок универсальных таблиц (~180 разделов), мультиселект, зубная формула, канбан, лицензии и касса.
- **Фазы 1–3** каждый трек проходит параллельно: MVP → паритет со старым фронтом → интеграции.
- **Фаза 4** — вместе: прогон всех разделов реестра, производительность, релиз (после исправления бэкенда).
