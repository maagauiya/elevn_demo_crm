## Философия

Это не сайт, который читают — это экран, по которому **сканируют** весь день. Администратор клиники держит это расписание открытым 8 часов подряд и должен за доли секунды понять: какая запись подтверждена, какая отменена, где окно для нового пациента. Из этого вытекают правила, прямо противоположные маркетинговому дизайну (Apple.com и подобные):

- **Цвет — это сигнал состояния, а не декор.** Статус обязан считываться периферийным зрением, без чтения текста. Поэтому используем закрашенный тон (10–15% заливка) + плотная полоса слева, а не тонкую линию на белом.
- **Плотность важнее воздуха.** Чем больше дня помещается на экран без скролла — тем меньше кликов и когнитивной нагрузки. Высота строки времени подбирается по минимальной читаемой карточке 30-минутного приёма, а не по эстетике.
- **Тень — это сигнал интерактивности, а не декор.** В статике элементы плоские (hairline-граница). Тень появляется только когда что-то "поднимается" — наведение на карточку, перетаскивание, всплывающее меню, модалка. Тень = «это сейчас активно/над остальным контентом», а не украшение.
- **Один акцентный цвет — для действий, НЕ для статусов.** Брендовый синий означает «нажми меня» (кнопки, ссылки, выбранная дата). Статусы приёмов — отдельная, closed-палитра, чтобы не путать «активное действие» и «состояние записи».
- **Статус никогда не кодируется только цветом.** Отменённая запись дополнительно зачёркнута текстом — для дальтоников и для печати в ч/б.

## Цвета

### Поверхности и текст

| Токен           | HEX     | Назначение                                      |
| --------------- | ------- | ----------------------------------------------- |
| `ink`           | #1d1d1f | Основной текст                                  |
| `ink-muted`     | #6b7280 | Вторичный текст (время, специальность, подписи) |
| `ink-faint`     | #9aa1ac | Третичный текст, плейсхолдеры                   |
| `canvas`        | #ffffff | Карточки, панели, сетка                         |
| `canvas-sunken` | #f6f7f9 | Фон страницы, фон инпутов                       |
| `hairline`      | #e4e7ec | Границы панелей, разделители колонок            |

### Акцент (только действия)

| Токен          | HEX     | Назначение                                           |
| -------------- | ------- | ---------------------------------------------------- |
| `accent`       | #0066cc | Primary-кнопки, ссылки, выбранная дата, фокус-кольцо |
| `accent-hover` | #0055ad | Hover/active состояние                               |
| `accent-tint`  | #e8f2fc | Фон выбранных чипов/табов                            |

### Сигнальные (ошибки и «сейчас»)

| Токен         | HEX     | Назначение                                                           |
| ------------- | ------- | -------------------------------------------------------------------- |
| `danger`      | #d92d20 | Линия текущего времени, текст ошибок валидации, деструктивные кнопки |

Красный не используется для статусов записей — только для «ошибка/опасное действие» и линии «сейчас».

### Статусы записей (closed-палитра, не пересекается с accent)

| Статус       | Заливка карточки | Полоса/текст-акцент           | Семантика                         |
| ------------ | ---------------- | ----------------------------- | --------------------------------- |
| Подтверждена | #e7f1fe          | #1565c9                       | Запись согласована, ждём пациента |
| В процессе   | #efecfd          | #6e56cf                       | Приём идёт прямо сейчас           |
| Ожидание     | #fdf2e2          | #b4790f                       | Требует подтверждения/звонка      |
| Завершена    | #e8f8ee          | #0f8a4c                       | Приём закрыт                      |
| Отменена     | #f1f1f3          | #7a7f8a (+ зачёркнутый текст) | Слот свободен повторно            |

Контраст заливка/текст подобран на AA для 13px+ текста.

**Статусы из базы → пять статусов дизайн-системы.** В базе (`MANIPULATIONSTATUS`, поле `AppStatusid`) девять статусов.
Карточка красится в один из пяти, а точное название статуса из базы показывается в подробностях записи.

| ID  | Статус в базе          | Статус дизайн-системы                |
| --- | ---------------------- | ------------------------------------ |
| 1   | Предварительная запись | Ожидание                             |
| 2   | Клиент пришёл          | В процессе                           |
| 3   | Выполненная услуга     | Завершена                            |
| 4   | Отменённая услуга      | Отменена                             |
| 5   | Подтверждённая запись  | Подтверждена                         |
| 6   | Запланированная услуга | Подтверждена                         |
| 7   | Нерабочее время        | — (блок «нерабочее время», см. ниже) |
| 8   | Онлайн-запись          | Ожидание (+ метка «онлайн»)          |
| 9   | Выполнена и чек пробит | Завершена                            |

**Нерабочее время** — не запись, а блокировка слота: `canvas-sunken` с диагональной штриховкой `hairline`,
без полосы слева и без тени, текст `ink-faint`. Не кликается как запись. Полоса слева всегда на 1–2 шага темнее заливки — это и есть основной сканируемый сигнал на расстоянии.

### Статусы графика работы

Ячейка «специалист × день» на экране графика работы. Новых цветов нет — переиспользуем тона статусов записей,
но это другой экран и другой смысл, поэтому в ячейке всегда есть текст: часы работы или сокращение статуса.
Цвета с сервера (`CNAME`: Green, DarkGray…) не используем.

| ID  | Статус        | Тон                       | Текст в ячейке |
| --- | ------------- | ------------------------- | -------------- |
| 1   | Рабочий       | «Завершена» (зелёный)     | часы, «10–20»  |
| 7   | Неполный день | «Ожидание» (янтарный)     | часы           |
| 2   | Выходной      | без заливки, `ink-faint`  | «вых»          |
| 3   | Отпуск        | «Подтверждена» (синий)    | «отп»          |
| 5   | Больничный    | «В процессе» (фиолетовый) | «бол»          |
| 4   | Отгул         | «Отменена» (серый)        | «отг»          |
| 6   | Прогул        | `danger-tint` / `danger`  | «прг»          |
| —   | Не заполнено  | `canvas`                  | пусто          |

Выделенная ячейка — кольцо `accent` 2px внутрь, без изменения заливки (статус остаётся читаемым).

### Графики (категориальная палитра)

Только для серий данных на графиках дашбордов. Не для статусов и не для действий. Порядок фиксирован:
серия N всегда получает слот N, цвета не перебираются по кругу. Девятая серия и дальше сворачиваются в «Прочее».
Цвета с сервера (`ITEMCOLOR`) не используем. Палитра проверена валидатором на белой поверхности: CVD ΔE ≥ 9.1,
различимость ≥ 19.6. Слоты 3, 4, 5 ниже 3:1 по контрасту, поэтому у графиков всегда есть легенда со значениями и тултипы.

| Слот | Токен     | HEX     |
| ---- | --------- | ------- |
| 1    | `chart-1` | #2a78d6 |
| 2    | `chart-2` | #eb6834 |
| 3    | `chart-3` | #1baf7a |
| 4    | `chart-4` | #eda100 |
| 5    | `chart-5` | #e87ba4 |
| 6    | `chart-6` | #008300 |
| 7    | `chart-7` | #6250d6 |
| 8    | `chart-8` | #e34948 |

Правила: одна ось Y (никаких двойных осей), линии 2px, сетка `hairline`, подписи осей `ink-muted` размером `micro`,
текст значений — цветом текста, а не цветом серии.

## Типографика

Системный стек: `-apple-system, BlinkMacSystemFont, "Inter", system-ui, sans-serif` — не маркетинговый SF Pro Display с крупными display-кеглями, а убористая текстовая шкала.

| Токен      | Размер | Вес | Line-height | Применение                                                                                               |
| ---------- | ------ | --- | ----------- | -------------------------------------------------------------------------------------------------------- |
| `title`    | 17px   | 600 | 1.2         | Заголовок страницы/дня                                                                                   |
| `subtitle` | 12px   | 400 | 1.3         | Подзаголовок (кол-во специалистов и т.п.)                                                                |
| `label`    | 13.5px | 600 | 1.25        | Имя пациента/врача, названия колонок                                                                     |
| `body`     | 13px   | 400 | 1.35        | Основной текст, услуга                                                                                   |
| `caption`  | 11.5px | 600 | 1.2         | Время, метки, статус-бейджи (вес 600, а не 400 — мелкий текст должен быть чуть жирнее для сканируемости) |
| `micro`    | 10.5px | 500 | 1.2         | Легенда, вспомогательные подписи                                                                         |

В отличие от Apple-палитры (300/400/600/700 без 500) — здесь **вес 500 используется намеренно** для средней насыщенности мелких UI-элементов (бейджи, чипы), это стандарт плотных интерфейсов (Linear, Notion), не маркетинговых.

## Spacing (база 4px)

`4 · 8 · 12 · 16 · 20 · 24 · 32` — мельче, чем у Apple (база 8px), потому что элементы управления (чипы, иконки тулбара) плотнее.

| Токен  | Значение | Применение                                                       |

## Elevation (тень = интерактивность)

| Уровень          | Стиль                                                   | Когда                                                               |
| ---------------- | ------------------------------------------------------- | ------------------------------------------------------------------- |
| Плоско           | только `hairline`-граница                               | Карточки/панели в покое                                             |
| Hover            | `0 2px 8px rgba(16,24,40,0.10)`                         | Наведение на карточку приёма — «эта карточка кликабельна»           |
| Поднято          | `0 8px 24px rgba(16,24,40,0.16)`                        | Перетаскиваемая карточка, открытое меню, попап                      |
| Плавающая кнопка | `0 6px 16px rgba(0,102,204,0.35)` (цветная тень accent) | FAB быстрого добавления — единственный постоянно «поднятый» элемент |

## Плотность / зум расписания

Высота часа — управляемая переменная, а не фикс:

- **Компакт (по умолчанию):** 80px/час — весь рабочий день (9:00–19:00) помещается почти без скролла.
- **Комфорт (тач/планшет ресепшена):** 112px/час — крупнее тап-зоны, меньше записей видно одновременно.

## Ключевые компоненты для этого продукта

- **Мини-календарь** — pill-выбор дня (accent), сегодня — accent-текст без заливки.
- **Сегмент-контрол тулбара** («По специалистам / По кабинетам») — pill-контейнер, активный таб — белая подложка + тень hover-уровня (чтобы отличался от плоских неактивных).
- **Filter-chip** — hairline-граница, hover → canvas-sunken.
- **Icon-button тулбара** — круг 36px, без фона в покое, `canvas-sunken` на hover.
- **Карточка приёма** — закрашенный статус-тон + полоса слева 4px; при 30-минутной длительности показывает время+имя (без услуги), при ≥45 мин — все три строки.
- **Current-time line** — красная линия через все колонки, точка слева, поверх сетки, без тени (не интерактивный элемент).
- **FAB быстрой записи** — единственная постоянная тень в системе (цветная, accent).
- **KPI-плитка / виджет-карточка дашборда** — та же hairline-логика: плоско в покое, тень только на hover/перетаскивании (drag resize виджетов).

## Do / Don't

**Делать:**

- Заливать статус-карточки закрашенным тоном — статус должен быть виден боковым зрением.
- Держать компакт-режим по умолчанию — видимость всего дня важнее воздуха.
- Добавлять тень только на интерактив (hover/drag/popover/FAB).
- Дублировать статус «отменено» зачёркиванием текста, а не только цветом.
- Использовать вес 500 для мелких UI-меток — это нормально для плотных интерфейсов.

**Не делать:**

- Не использовать accent-синий для статуса «подтверждено» один в один с цветом primary-кнопок — это путает «действие» и «состояние» (при необходимости — отдельный, более приглушённый синий для статуса).
- Не растягивать высоту строки/карточки ради «воздуха» — в плотном инструменте это стоит пользователю лишнего скролла и времени.
- Не убирать тень у элементов, которые реально поднимаются над контентом (drag, popover, FAB) — без неё теряется физика интерфейса.
- Не кодировать статус только цветом без текстового/графического дублирования.
