# AGENT.md

Операционные правила для AI-агентов (Claude Code и других), работающих в этой папке.

## Границы

- Разрешено: создавать/редактировать `.html`, `.css`, `.js` файлы внутри этой папки,
  обновлять `design-system.md`, добавлять skill-файлы в `skills/`.
- Запрещено без явного запроса пользователя: выходить за пределы `frontend/mockup/`,
  трогать остальные части монорепозитория `haim-crm` (`backend/`, `db/`, `deploy/`,
  `docker-compose*.yml` и т.п.), делать git-коммиты, пуши, инициализировать сборку/npm.

## Как проверять результат

- У проекта нет шага сборки. Проверка — открыть `.html`-файл напрямую в браузере или
  поднять простой статический сервер (`python3 -m http.server`) в этой папке.
- Перед тем как считать задачу готовой — открыть изменённую страницу в браузере и
  визуально сверить с `design-system.md` (цвета статусов, плотность, тени только на
  интерактиве и т.д.), а не только проверить, что HTML валиден.

## Дизайн-система — источник истины

`design-system.md` описывает философию (плотность важнее воздуха, цвет = сигнал
состояния, тень = интерактивность) и конкретные токены (цвета, типографика, spacing,
радиусы, elevation). Любой новый экран или компонент должен ссылаться на эти токены,
а не вводить свои значения. Если токена не хватает — предложить добавление в
`design-system.md`, а не обходить его инлайн-стилями.

## Skills

Специфичные для этого проекта инструкции (например, "как верстать карточку приёма",
"как делать статус-бейджи") кладутся в `skills/` отдельными файлами по мере появления
повторяющихся задач.
