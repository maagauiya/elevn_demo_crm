# CLAUDE.md

Этот файл задаёт контекст для Claude Code при работе в этой папке.

## Что это за проект

Это **изолированный HTML-мокап** для рефакторинга фронтенда Sycret CRM (бывший haim-crm).
Цель — проверять новый UI/UX на статичных HTML-страницах, до переноса логики в реальный
фронтенд-стек приложения. Папка физически лежит внутри монорепозитория `haim-crm`
(`frontend/mockup`), но имеет собственный git-репозиторий и живёт по своим правилам.

## Технические ограничения

- Только **чистый HTML/CSS/JS**. Никаких фреймворков, сборщиков, npm-зависимостей и
  шагов сборки — страницы должны открываться прямо в браузере (`file://`) или через
  простой статический сервер.
- Никакой реальной бизнес-логики, API-запросов к бэкенду или реальных данных пациентов —
  все данные в мокапах должны быть вымышленными/синтетическими.
- Дизайн-токены (цвета, типографика, spacing, тени) брать из `design-system.md` — не
  изобретать новые значения на глаз.

## Структура

- `design-system.md` — дизайн-система продукта (философия, цвета, типографика, spacing,
  elevation, компоненты, do/don't). Читать перед любой версткой.
- `dashboard.html`, `logbook.html` — существующие экраны-мокапы.
- `skills/` — переиспользуемые skill-инструкции для конкретных задач в этом проекте.
- `SECURITY.md` — политика безопасности для этой папки.
- `AGENT.md` — операционные правила для AI-агентов, работающих здесь.

## Рабочий процесс

1. Перед версткой нового экрана — проверить `design-system.md` на предмет существующих
   токенов/компонентов, которые подходят к задаче.
2. Если нужен новый паттерн, которого нет в дизайн-системе — сначала предложить его и
   обновить `design-system.md`, а не плодить разовые стили прямо в HTML.
3. Изменения здесь не должны затрагивать `backend/`, `db/`, `deploy/` и другие части
   монорепозитория `haim-crm` — эта папка самодостаточна.
4. Коммитить только по явной просьбе пользователя.
