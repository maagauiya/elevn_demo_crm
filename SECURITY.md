# SECURITY.md

## Модель угроз

Эта папка содержит только статичные HTML/CSS/JS мокапы интерфейса. Здесь нет:

- бэкенда, API-ключей, токенов доступа;
- подключения к базе данных или реальных учётных данных;
- реальных данных пациентов/клиентов — любые имена, расписания и записи в мокапах
  должны быть синтетическими (придуманными), не взятыми из продакшена.

## Правила для контента мокапов

- Не вставлять в HTML/JS реальные персональные данные (ФИО, телефоны, диагнозы и т.п.),
  даже "для примера" — использовать явно вымышленные значения.
- Не хардкодить секреты (API-ключи, пароли, токены) — в статичном UI им нет причин
  присутствовать вовсе.
- Внешние скрипты/шрифты подключать только с доверенных CDN по HTTPS; избегать
  произвольного удалённого кода без необходимости.

## Если нужно подключить что-то живое

Когда мокап будет переноситься в реальное приложение и потребуется реальный API —
это выходит за рамки данной папки и должно обсуждаться отдельно, с учётом security-
практик основного проекта `haim-crm` (см. корневой `README.md` и `.env.*.example`).

## Сообщить о проблеме

Если найдена случайно попавшая в мокап реальная/чувствительная информация — удалить
её немедленно и сообщить ответственному за проект.
